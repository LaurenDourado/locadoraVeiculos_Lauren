# 🚗 Sistema de Administração - Locadora de Veículos

Este é um **projeto pedagógico** desenvolvido com o objetivo de praticar conceitos de **HTML**, **CSS**, **Bootstrap** e **estrutura de sistemas web com PHP**. A aplicação simula o painel administrativo de uma locadora de veículos.

---

## 📋 Funcionalidades

- ✅ Cadastro de veículos (modelo, placa e tipo)
- 📅 Cálculo de previsão de aluguel com base no número de dias
- 🧾 Listagem de veículos cadastrados
- 📦 Aluguel e devolução de veículos
- ❌ Remoção de veículos (função disponível apenas para o administrador)
- 👤 Interface com saudação ao usuário (estático, mas preparado para integração com login)

---

## 🧰 Tecnologias Utilizadas

- `HTML`
- `CSS`
- `Bootstrap 5` (para estilização e responsividade)
- `Bootstrap Icons` (para os ícones)
- `PHP` (placeholder para futura integração com backend)
